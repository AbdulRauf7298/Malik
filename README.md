# Malik Academic Writing Services

This repository contains a complete single-page website for Malik Academic Writing Services,
including a pricing guide, order processing form, and front-end/back-end dashboard previews.

## Preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
cd /home/runner/work/Malik/Malik
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
